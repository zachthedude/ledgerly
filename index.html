    How the agent works

    Courier statements are messy. Order numbers get typed wrong, end up in a note, or one payment arrives as two lines. Matching by rules treats all of that as missing money, so real shortfalls hide among false alarms.

    When you press Check with the agent, an OpenAI model works through your files using five tools that run in your browser:

    1. Inspect files. Reads column names and a few rows.
    2. Map columns and reconcile. Picks which column is the order ID, the amount, the fee. Ledgerly's own code then does every calculation.
    3. Propose match. Links a stray statement line to an order and says why. It changes nothing until you approve.
    4. Draft claim. Writes a message to the courier in English or Bangla. Every taka amount is checked against the ledger; a wrong amount is sent back to the agent to fix.
    5. Finish. Summarises what it found.

    The model never does arithmetic and never sends anything. You approve matches and send claims yourself.
