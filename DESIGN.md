# Ledgerly design notes

Reading this as: a reconciliation workspace for small Bangladeshi online sellers, in the visual language of a hisab khata (shopkeeper's ledger book). Dial: ENERGY 2 / RHYTHM 2 / MOTION 2.

| Decision | Reason |
|---|---|
| Ledger paper `#EDF0E8`, ink `#18263A`, ruling blue `#C9D5E1` | The khata is the tool sellers already use for money; blue-black ink on ruled paper reads as accounts, not tech. |
| Red `#B4232A` only for money owed and the margin | Red ink means "in the red" in bookkeeping. One meaning makes owed amounts findable at a glance. |
| Green `#276245` only for matched rows | The single accent for settled. |
| Anek Bangla, one family | Built for Bangla and Latin, so Bangla claim drafts render properly. Its width axis gives the headline a wide ledger-heading stance without a second font. |
| Headline is a sentence about the money gap | The seller's question is "did I get paid?", so the answer is the focal point, not four stat cards. |
| No sidebar; two views in the top bar | There are only two jobs (reconcile, claim). A sidebar would add empty navigation. |
| Double red margin in the work sheet is the step timeline | The identity motif, and it carries information: each agent step is an entry on the margin. |
| 3px red inset on owed rows | Marks state (money owed), not decoration. |
| Radii 4 / 7 / 12 px | Small for controls, larger for panels, so hierarchy reads through shape. |
| Shadow only on dialogs and toasts | They are the only surfaces above the page. |
| Motion: agent steps fade in as they really happen | The one moment worth watching. Respects reduced motion. |
| Light and dark follow the system setting | Sellers check payouts at night on phones; both themes are tested. |
